# Dialogue format

Every spoken line uses explicit label format:

```text
Mari: “...”
Sanya: “...”
Eli: “...”
```

Narration remains unlabelled. Name the acting character whenever a new paragraph could plausibly belong to more than one present character; pronouns are fine only while action ownership remains uninterrupted and unambiguous. This is intentional markup for later CSS voice-family styling, not a screenplay format. Use character's canonical name as label once known to project; labels may reveal a name before the POV character learns it.
