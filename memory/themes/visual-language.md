# Visual language

Lived-in Night City, not clean sci-fi: dirty reds, magenta, cyan, toxic blue, deep shadow, wet reflections, cheap furniture, practical lamps, cables, and medical/commercial tech embedded in daily life. Avoid decorative neon clutter, random signage, glamour, and weaponized action imagery.

Mari reads warmer in red/amber: physically present, grounded, alive. Sanya reads colder in blue/cyan: calm, distant, almost euphoric when physical body becomes background noise. Core image: Mari holds Sanya close while Sanya's consciousness is elsewhere.
